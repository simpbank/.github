# 💳 Simpbank

**Soluções financeiras e tecnologia de pagamentos com foco em inclusão, inovação e impacto social.**

A Simpbank é uma empresa brasileira de tecnologia financeira comprometida com a democratização do acesso ao crédito e à modernização dos serviços financeiros no país.

---

## 🌟 Nossos pilares

- 💡 Inovação com propósito
- 🔒 Segurança e transparência
- 🚀 Inclusão financeira de verdade
- 🤝 Tecnologia a serviço das pessoas

---

## 🧠 Tecnologias que utilizamos

- **Backend:** Java, Spring Boot, RabbitMQ, TypeScript
- **Frontend/Mobile:** Flutter, Node.js
- **Banco de Dados:** PostgreSQL, SQL Server
- **Infraestrutura:** Docker, AWS
